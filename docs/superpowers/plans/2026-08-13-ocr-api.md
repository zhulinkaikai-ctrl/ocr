# OCR API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add FastAPI endpoints for ID-card-front and business-license OCR using Base64 or public image URLs.

**Architecture:** Keep HTTP validation, image acquisition, response construction, and document extraction separate. Routes turn a JSON request into validated image bytes, invoke the existing PaddleOCR adapter, and map OCR lines to fixed external response contracts.

**Tech Stack:** Python 3.12, FastAPI, Uvicorn, HTTPX, Pillow, PaddleOCR, unittest.

---

## File Structure

- `api_app.py`: FastAPI application entry point.
- `ocr_api/schemas.py`: Request model and API constants.
- `ocr_api/image_loader.py`: Base64 decoding, public URL validation, SSRF protection, bounded image download and Pillow validation.
- `ocr_api/responses.py`: Fixed success/error response builders.
- `ocr_api/routes.py`: Health, ID-card and business-license routes.
- `id_card_ocr/business_license.py`: Business-license rule-based extraction from OCR lines.
- `tests/test_image_loader.py`: Image source and SSRF validation tests.
- `tests/test_business_license.py`: Business-license OCR text extraction tests.
- `tests/test_api_responses.py`: Response contract tests.
- `tests/test_api_routes.py`: FastAPI endpoint tests with OCR dependency overrides.
