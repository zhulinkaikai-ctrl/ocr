# 身份证 OCR 本地 Demo 需求文档

## 背景

第一版目标是快速验证 PaddleOCR 对居民身份证图片的识别闭环。系统作为本地网页 Demo 运行，不上传、不保存身份证图片或识别结果。

## MVP 范围

- 本地运行的 Streamlit 网页工具。
- 用户上传单张身份证单面图片。
- 使用 PaddleOCR 进行文字检测和识别。
- 使用 PaddleOCR 自带方向分类能力，不额外做复杂图像增强。
- 自动判断身份证正面或反面。
- 抽取结构化字段。
- 页面展示图片预览、只读字段表单、可复制 JSON。
- 字段展示基础校验状态：通过、缺失、疑似错误。

## 第一版不做

- PDF 识别。
- 批量处理。
- 账号、权限、历史记录或数据库。
- 图片和识别结果持久化保存。
- 云端部署。
- 表格识别、全文排版、可搜索 PDF。
- 复杂拍照增强、去阴影、透视矫正。

## 证件类型

- 居民身份证。
- 第一版假设单张图片只包含正面或反面其中一面。

## 字段

### 正面

- 姓名
- 性别
- 民族
- 出生日期
- 住址
- 公民身份号码

### 反面

- 签发机关
- 有效期限

## JSON 结构

JSON 使用中英结合结构，便于页面展示和后续系统集成：

```json
{
  "证件类型": "居民身份证",
  "证件面": "正面",
  "字段": [
    {
      "key": "name",
      "label": "姓名",
      "value": "张三",
      "status": "通过",
      "confidence": 0.98
    }
  ]
}
```

## 校验规则

- 公民身份号码：校验长度、字符范围、出生日期段、校验位。
- 出生日期：校验是否为有效日期。
- 正面字段：缺失时标记为缺失。
- 反面字段：缺失时标记为缺失。
- 与当前证件面无关的字段不作为错误。

## 成功标准

- 能通过本地命令启动网页。
- 能上传一张身份证正面或反面图片。
- 能显示 OCR 识别出的结构化字段。
- 能复制包含字段明细、状态、置信度的 JSON。
- 不在本地项目中保存上传的身份证图片或识别记录。
